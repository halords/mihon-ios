Browser verification on your VPS

The PWA can use a Chromium session hosted on Ubuntu. This needs no Mac, iOS app or Apple developer membership.

  1. Install Docker Engine and Compose on the VPS. Clone the app repository.
  2. Copy .env.example to .env. Generate a private token with openssl rand -hex 32 and set SOURCE_BROWSER_TOKEN. Set MIHON_DOMAIN to your domain.
  3. Point the domain to the VPS and allow HTTPS ports 80/443 in Ubuntu and Oracle networking.
  4. Run docker compose -f compose.browser.yaml up -d --build.
  5. Open the HTTPS PWA, then Connections → Browser verification. Choose the source, open its browser, complete website verification yourself, and press Use this session.

All backup sources remain supported; there is no fixed session count cap. On a 1 GB VPS, available RAM determines usable concurrency. Idle browsers close after three minutes and reopen with saved cookies. Optional swap can help with memory spikes.

If your PWA stays on Vercel, run the browser service behind HTTPS on the VPS and set SOURCE_BROWSER_URL and the same private SOURCE_BROWSER_TOKEN in Vercel's server environment. Do not put the token in browser settings or VITE_* variables.

Some sites still reject the VPS IP or browser. This service has no automated challenge solver. A successful session must be checked on your deployed VPS.
